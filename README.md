## How to use this repository

Each numbered example is intentionally kept separate.

Every example folder contains its own detailed README with:

- the concepts used
- important APIs and tools
- exact code snippets worth studying
- implementation details and data flow
- coding, data-structure, and mathematical fundamentals
- course notes and observations where available

The root README is only a **navigation tracker**. Detailed learning material belongs inside the corresponding numbered folder.
