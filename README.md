## How to use the repository

Each numbered example is kept separate. Start with its local `README.md` for a guided explanation, then inspect the source file paths and snippets named there.

Every module aims to document:
- exact code worth studying and why it matters
- Android APIs and app-development patterns
- mathematics and coordinate conventions
- data structures, algorithms, limitations, and tests

**The root README is only a navigation tracker.** Keep detailed explanations in each feature's dedicated folder.
